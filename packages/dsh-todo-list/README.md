# 待办清单 · @hankerlove/dsh-todo-list

悬浮在 [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness)（DSH）Web UI 里的待办面板，用法接近 iOS 的「提醒事项」。

| 项 | 值 |
| --- | --- |
| npm 包名 | `@hankerlove/dsh-todo-list` |
| 版本 | `0.1.0` |
| 适用 | DSH Web UI（在 DSH `0.2.2-rc.1` 上验证） |
| 协议 | [MIT](../../LICENSE) |

## 能做什么

| 能力 | 说明 |
| --- | --- |
| 悬浮面板 | 默认停在页面右上角；拖动标题栏可移动；可收起成悬浮小胶囊，胶囊也能拖动；准星按钮或双击标题栏回到默认位置 |
| 按天查看 | 一次只显示一天，默认今天；`‹` `›` 逐日翻页、点日期可跳任意一天；「逾期 N」「未来 N」快速跳到对应日期；翻到过去某天可以看到当天的完成与未完成记录 |
| 添加待办 | 标题 + 日期（默认今天）+ 可选时间 + 重复规则 + 优先级；回车或「＋」添加，添加后表单复位 |
| 优先级 | 无 / P0 / P1 / P2；行首色条加彩色徽章（P0 红、P1 琥珀、P2 蓝） |
| 重复规则 | 不重复 / 工作日 / 周末 / 每天 / 每周 / 每月 / 每年；工作日与周末按中国法定节假日与调休安排（内置 2026–2027 年） |
| 完成与历史 | 勾选后变灰划线并移到底部「已完成」；重复事项错过的当次记录在「未完成」，不会变成今天的逾期任务；历史最多保留 200 条 |
| 到点提醒 | 页内提醒卡片（完成 / 稍后 10 分钟 / 知道了）+ 轻提示音；系统与 WebView 支持时还会发系统通知、更新应用角标 |
| 多语言 | 中英文界面，跟随 DSH 当前语言；日期与星期本地化 |

## 安装

`<profile>` 换成你的 profile 名（例如 `desktop`）。

```sh
# 从 npm 安装（npm 上发布之后可用；尚未发布时用下面两种方式）
dsh plugin --profile <profile> add @hankerlove/dsh-todo-list

# 或从 tarball 安装
cd packages/dsh-todo-list
pnpm pack
dsh plugin --profile <profile> add ./hankerlove-dsh-todo-list-0.1.0.tgz

# 或从源码目录安装
dsh plugin --profile <profile> add ./packages/dsh-todo-list
```

安装后用该 profile 启动 DSH 并刷新 Web UI 页面，面板会出现在页面右上角。

卸载：

```sh
dsh plugin --profile <profile> remove @hankerlove/dsh-todo-list
```

## 使用

### 位置与收起

- 默认位置在页面右上角；按住标题栏可拖动整张卡片。
- 标题栏右侧的收起按钮把它缩成小胶囊：胶囊出现在卡片当前位置的顶部中央，靠近屏幕边缘会自动内收。胶囊本身可以拖动，它的位置单独记忆。
- 点击胶囊（没有拖动时）重新展开，卡片回到收起前的位置。
- 双击标题栏，或点准星按钮，把卡片放回默认的右上角。

### 按天查看

- 头部是大号日期 `YYYY/MM/DD` 与星期，左侧 `‹`、右侧 `›` 逐日切换；点击日期可直接选任意一天。
- 不在今天时会出现「回到今天」。
- 还有别的日期的事项时，会出现「逾期 N」（跳到最早的逾期日期）和「未来 N」（跳到最近的未来日期）。
- 今天只显示今天的内容；未来日期的事项不会挤在今天的列表里，翻到那一天即可查看。

### 添加待办

- 第一行：标题输入框 + 「＋」按钮，按回车也能提交（输入法组合中的回车不会误提交）。
- 第二行：日期（默认今天）+ 可选时间。
- 第三行：重复规则 + 优先级。
- 每次添加成功后表单复位为「今天 / 无时间 / 不重复 / 无优先级」；如果加到了别的日期，会短暂提示「已添加到 `YYYY/MM/DD`」。

### 重复规则与工作日历

| 规则 | 行为 |
| --- | --- |
| 不重复 | 只到期一次 |
| 工作日 | 周一至周五，排除法定节假日，包含调休上班日 |
| 周末 | 周六、周日，排除调休上班日 |
| 每天 / 每周 | 次日 / 7 天后 |
| 每月 / 每年 | 下个月同日 / 次年同日；目标月没有该日时取当月最后一天 |

- 工作日历取自国务院办公厅 2026 年与 2027 年节假日安排的通知；**只覆盖这两年**，之外「工作日」回退为周一至周五，「周末」回退为周六与周日。
- 选择「工作日 / 周末」时，如果所选日期不匹配，会自动顺延到之后第一个匹配的日期。

### 完成与历史

- 圆形勾选框；勾选后该行变灰、划线，移到底部「已完成」分组，可以取消。
- 重复事项完成后会显示「下次：…」，下一次到期时自动回到列表；中间错过的周期记录在「未完成」里。
- 底部「清除」删除已完成的一次性事项并清空历史记录。

### 提醒

- 只有带时间（时:分）的待办会触发提醒；到点后只要页面开着，会：
  - 在页面顶部正中弹出提醒卡片（即使待办面板已收起也能看到）：**完成**、**稍后 10 分钟**、**知道了**；卡片不会自动消失，最多同时显示 3 张，其余汇总为「还有 N 项到点」；
  - 播放一段轻提示音；
  - 在系统与 WebView 支持时发系统通知、更新应用角标。
- 标题栏右侧的铃铛控制提醒开关，默认开启；关闭后不再提醒（到点的条目仍记为已处理）。
- 每个到点时刻只提醒一次；页面唤醒时已经晚了 5 分钟以上的提醒不会补发。
- 提示音与页内提醒卡片不需要通知权限；系统通知与应用角标取决于 WebView 与操作系统，权限被拒绝时回落为页内提醒 + 提示音。

## 数据与隐私

| 存储键 | 内容 |
| --- | --- |
| `dsh.todo-list.v2` | 待办与历史记录（标题、日期、时间、重复规则、优先级、完成状态、已提醒标记等） |
| `dsh.todo-list.view.v3` | 卡片位置、胶囊位置、是否收起 |
| `dsh.todo-list.settings.v1` | 提醒开关 |

- 全部写在当前页面的浏览器 `localStorage` 里，不经过 Host、不上传、不发起网络请求。
- 数据按浏览器 profile / 站点隔离，不跨设备同步。
- 卸载插件不会自动删除这些数据；清除站点数据会一并丢失。

## 已知限制

- 只存在于 DSH Web UI；终端、headless 等场景不可用。
- 工作日历只覆盖 2026–2027 年，之后需要更新内置的节假日表。
- 提醒只在页面打开时工作；系统通知、应用角标与提示音的可用性取决于 WebView 与操作系统；后台标签页的定时器可能被节流，提醒可能稍有延迟。
- 提醒卡片与「稍后 10 分钟」是页面内的临时状态，刷新后不会恢复。
- 数据存在浏览器本地，不跨设备、不支持导入导出。
