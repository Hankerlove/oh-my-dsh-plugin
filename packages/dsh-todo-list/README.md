# 待办清单 · @ultraslow/dsh-todo-list

悬浮在 [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness)（DSH）Web UI 里的待办面板。

| 项 | 值 |
| --- | --- |
| npm 包名 | [`@ultraslow/dsh-todo-list`](https://www.npmjs.com/package/@ultraslow/dsh-todo-list) |
| 版本 | `0.2.0` |
| 适用 | DSH Web UI |
| 协议 | [MIT](../../LICENSE) |

## 能做什么

| 能力 | 说明 |
| --- | --- |
| 悬浮面板 | 默认停在页面右上角；拖动标题栏可移动；可收起成悬浮小胶囊，胶囊也能拖动；准星按钮或双击标题栏回到默认位置 |
| 按天查看 | 一次只显示一天，默认今天；`‹` `›` 逐日翻页、点日期可跳任意一天；翻到过去能看到当天的完成与未完成记录，未来日期只读 |
| 添加待办 | 标题 + 日期（默认今天）+ 可选时间 + 重复规则 + 优先级；回车或「＋」添加，添加后表单复位 |
| 优先级 | 无 / P0 / P1 / P2；行首色条加彩色徽章（P0 红、P1 琥珀、P2 蓝） |
| 重复规则 | 不重复 / 工作日 / 周末 / 每天 / 每周 / 每月 / 每年；每个触发日生成一条独立实例，完成今天不影响明天 |
| 完成与历史 | 勾选只影响当天实例；漏做的重复事项只在当天记「未完成」，不算逾期；实例不会自动清理 |
| 到点提醒 | 每天/每个实例单独提醒：页内提醒卡片（完成 / 稍后 10 分钟 / 知道了）+ 轻提示音；系统与 WebView 支持时还会发系统通知、更新应用角标 |
| 多语言 | 中英文界面，跟随 DSH 当前语言；日期与星期本地化 |

## 安装方式

`<profile>` 换成你的 profile 名（例如 `desktop`、`web`）。

### 从 npm 安装

```sh
dsh plugin --profile <profile> add @ultraslow/dsh-todo-list
```

### 从源码安装

```sh
git clone https://github.com/Hankerlove/oh-my-dsh-plugin.git
cd oh-my-dsh-plugin
dsh plugin --profile <profile> add ./packages/dsh-todo-list
```

安装后用该 profile 启动 DSH，并刷新 Web UI 页面，面板会出现在页面右上角。

卸载：

```sh
dsh plugin --profile <profile> remove @ultraslow/dsh-todo-list
```

## 使用

### 位置与收起

- 默认位置在页面右上角；按住标题栏可拖动整张卡片。
- 标题栏右侧的收起按钮把它缩成小胶囊：胶囊出现在卡片当前位置的顶部中央，靠近屏幕边缘会自动内收。胶囊本身可以拖动，它的位置单独记忆。
- 点击胶囊（没有拖动时）重新展开，卡片回到收起前的位置。
- 双击标题栏，或点准星按钮，把卡片放回默认的右上角。

### 按天查看

- 头部是大号日期 `YYYY/MM/DD` 与星期，左侧 `‹`、右侧 `›` 逐日切换；点击日期可直接选任意一天。
- 不在今天时会出现「回到今天」。
- 今天只显示今天的内容；重复事项每天各有一条实例，翻到对应日期即可查看。
- 过去日期只读展示历史，但没完成的实例可以补勾（记为当天完成）；未来日期只读，不能提前勾选。

### 添加待办

- 第一行：标题输入框 + 「＋」按钮，按回车也能提交（输入法组合中的回车不会误提交）。
- 第二行：日期（默认今天）+ 可选时间。
- 第三行：重复规则 + 优先级。
- 选择「不重复」创建一条一次性待办；选择其他重复规则会创建一条规则，并为每个触发日生成独立实例。
- 每次添加成功后表单复位为「今天 / 无时间 / 不重复 / 无优先级」；如果加到了别的日期，会短暂提示「已添加到 `YYYY/MM/DD`」。

### 重复规则与工作日历

| 规则 | 行为 |
| --- | --- |
| 不重复 | 只到期一次 |
| 工作日 | 周一至周五，排除法定节假日，包含调休上班日 |
| 周末 | 周六、周日，排除调休上班日 |
| 每天 / 每周 | 次日 / 7 天后 |
| 每月 / 每年 | 下个月同日 / 次年同日；目标月没有该日时取当月最后一天 |

重复事项按下面的方式运行：

- 规则会为每个触发日生成一条**独立实例**：今天、明天、下个工作日各一条；默认提前生成未来 30 天，翻到更远的日期会按需补充。
- 勾选/取消只影响当天那条实例，完成今天不会把明天标成完成，也不会停掉明天的提醒。
- 未来日期的实例只读（勾选框禁用）；今天和过去的实例可以勾选，过去漏做的可以补勾。
- 漏做不算逾期：没完成的那天只在当天留下「未完成」记录，不会滚到第二天，也不进入「逾期」计数；「逾期 N」只统计过期的一次性待办。
- 重复实例不自动清理（每天一条，一年约 365 条/规则），历史会一直保留。
- 删除重复实例时可以选择「仅跳过本次」或「删除整个重复」；删除整个重复会停止生成新实例，已经完成的记录保留。

#### 更新内置的节假日表

新一年的安排发布后，把日期补进插件里的两张表即可（不需要改逻辑，也不需要重新构建）：

- `packages/dsh-todo-list/client.js` 顶部的 `CN_HOLIDAYS`：放假日期；
- 同一处的 `CN_MAKEUP_WORKDAYS`：调休上班日（周末需要上班的日期）。

两张表都用 `'YYYY-MM-DD'` 格式的字符串，按日期增删即可；没有列进去的年份会自动回退为「周一至周五 / 周六周日」。修改后刷新 Web UI 页面即可生效。

### 完成与历史

- 勾选只影响当天那条实例：变灰、划线，移到底部「已完成」分组；取消勾选即可恢复。
- 当天没完成的重复实例会出现在「未完成」分组，可以补勾；它不会变成今天的逾期任务。
- 一次性待办过期后会出现在「逾期 N」入口，点进去可以补勾。
- 「清除」删除所有已完成记录与历史记录，操作不可恢复。
- 如果某个重复事项由未来实例在预览，勾选框是禁用的，不能提前完成。

### 提醒

- 每个实例单独提醒：只有带时间（时:分）的当天实例会触发，今天完成不会影响明天的提醒。
- 到点后只要页面开着，会：
  - 在页面顶部正中弹出提醒卡片（即使待办面板已收起也能看到）：**完成**、**稍后 10 分钟**、**知道了**；卡片不会自动消失，最多同时显示 3 张，其余汇总为「还有 N 项到点」；
  - 播放一段轻提示音；
  - 在系统与 WebView 支持时发系统通知、更新应用角标。
- 标题栏右侧的铃铛控制提醒开关，默认开启；关闭后不再提醒（到点的条目仍记为已处理）。
- 每个到点时刻只提醒一次；页面唤醒时已经晚了 5 分钟以上的提醒不会补发。
- 提示音与页内提醒卡片不需要通知权限；系统通知与应用角标取决于 WebView 与操作系统，权限被拒绝时回落为页内提醒 + 提示音。

## 数据与隐私

| 存储键 | 内容 |
| --- | --- |
| `dsh.todo-list.v3` | `{ series, todos, history }`：重复规则、每天/每个触发日的实例、从旧版本迁移来的记录 |
| `dsh.todo-list.view.v3` | 卡片位置、胶囊位置、是否收起 |
| `dsh.todo-list.settings.v1` | 提醒开关 |
| `dsh.todo-list.v2` / `dsh.todo-list.v1` | 旧版数据，只在首次升级时读取，不主动删除 |

- 全部写在当前页面的浏览器 `localStorage` 里，不经过 Host、不上传、不发起网络请求。
- 从 0.1.x 升级到 0.2.x 时，旧的重复待办会自动转换为「规则 + 实例」，旧的一次性待办和历史记录保留；升级后新状态写入 v3。
- 数据按浏览器 profile / 站点隔离，不跨设备同步。
- 卸载插件不会自动删除这些数据；清除站点数据会一并丢失。
